# Скрапер вакансий — Yandex · Yango · Plata · inDrive

Раз в неделю проверяет открытые вакансии в четырёх компаниях, отбирает подходящие
по ключевым словам (M&A / BizDev / стратегия / финансы) и по региону LatAm,
пишет всё в CSV-лог и присылает **только новые** вакансии в Telegram.

## Как это устроено

| Источник | Как читаем | Надёжность |
|----------|-----------|-----------|
| **Plata Card** | публичный JSON API (Greenhouse) | высокая |
| **inDrive** | JSON API (Pinpoint), запасной вариант — HTML careers-страница | высокая |
| **Yango** | браузер (Playwright), сайт на JS | средняя (зависит от вёрстки) |
| **Yandex** | браузер (Playwright), сайт на JS | средняя (с дата-центров бывает капча) |

- `data/vacancies.csv` — накопительный лог всех найденных подходящих вакансий (можно открыть в Excel).
- `data/seen.json` — служебный файл: какие вакансии уже видели, чтобы отличать новые.
- На **первом** запуске уведомления не шлются — просто заполняется база. Со второго запуска приходят только новинки.

## Быстрый старт (локально)

Нужен **Node.js 20+** ([скачать](https://nodejs.org)). Проверить: `node --version`.

```bash
cd vacancy-scraper
npm install                 # поставить зависимости
npm run install:browser     # поставить Chromium для Playwright (один раз)
npm run test:filter         # проверить, что фильтр работает (не ходит в сеть)
npm start                   # запустить полный сбор
```

После `npm start` посмотри `data/vacancies.csv` — там будут вакансии.
Без настроенного Telegram новые вакансии просто печатаются в консоль.

> Если какой-то источник вернул `0 вакансий` или `ОШИБКА` — это не ломает остальные.
> Пришли мне вывод в консоли, и я подправлю разбор именно этого источника
> (у Yango/Yandex вёрстка может меняться).

## Настройка фильтра

Всё в файле `config.js`, код трогать не нужно:

- `keywords` — список паттернов (регекс). Вакансия подходит, если название **или**
  описание совпало хотя бы с одним.
- `latamCountries` — список стран/городов LatAm.
- `filterMode` — как комбинировать:
  - `keywords_or_latam` (по умолчанию) — подходит, если ключевые слова **или** LatAm;
  - `keywords_and_latam` — только если **и** ключевые слова, **и** LatAm;
  - `keywords_only` / `latam_only` / `all`.
- `sources` — включить/выключить любой источник флагом `enabled`.

## Telegram-уведомления

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи **токен**.
2. Напиши своему новому боту любое сообщение (иначе он не сможет тебе писать).
3. Узнай свой **chat_id**: открой в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id": ЧИСЛО}`.
4. Локально: скопируй `.env.example` → `.env` и впиши `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
5. В GitHub: положи их в **Secrets** (см. ниже).

## Автозапуск раз в неделю (GitHub Actions)

Так проверка идёт сама, **без включённого компьютера** — на серверах GitHub.

1. Создай на GitHub новый репозиторий (например, `vacancy-scraper`), можно приватный.
2. Залей туда содержимое этой папки:
   ```bash
   cd vacancy-scraper
   git init
   git add .
   git commit -m "init: vacancy scraper"
   git branch -M main
   git remote add origin https://github.com/<логин>/vacancy-scraper.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**
   добавь два секрета: `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
4. Всё. Расписание уже прописано в `.github/workflows/weekly.yml`
   (понедельник, 09:12 МСК). Проверить вручную можно на вкладке **Actions →
   Weekly vacancy check → Run workflow**.

Обновлённые `data/vacancies.csv` и `data/seen.json` бот сам коммитит обратно
в репозиторий после каждого прогона — так копится история и не теряется список «виденных».

### Важно про Yandex на GitHub
С серверов GitHub (дата-центровые IP) Yandex иногда показывает капчу и вернёт 0 вакансий.
Plata, inDrive и Yango обычно работают. Если Yandex важен именно на автозапуске —
проще запускать скрапер локально (например, через планировщик Windows), где капчи нет.

## Частые вопросы

**Ничего не пришло в Telegram.** На первом запуске так и должно быть — база
инициализируется. Со второго запуска придут новые. Либо новых вакансий правда нет.

**Источник вернул 0.** Для Yango/Yandex — возможно, поменялась вёрстка сайта.
Пришли вывод консоли, поправлю селекторы. Для inDrive — сработает запасной HTML-режим.

**Хочу добавить компанию.** Если у неё Greenhouse/Lever/Ashby/Pinpoint — добавить
источник просто (по аналогии с `plata.js`). Скажи какую — помогу.
